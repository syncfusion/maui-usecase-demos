# maui-usecase-demos
This repository contains Syncfusion .NET MAUI use case demos that showcase practical scenarios and sample implementations to help developers understand how to apply Syncfusion MAUI controls in real-world applications.

## Available Samples

### Patient Care Sample
A healthcare management application built with .NET MAUI that demonstrates Syncfusion controls in a realistic patient care scenario. The application includes dashboard metrics, appointment scheduling, patient management, and care plan tracking.

Location: `Use Case Samples/PatientCare/`

### Weather Forecast Sample
A weather forecast application that demonstrates various Syncfusion MAUI controls for displaying weather data.

Location: `WeatherForecast/`

### SfDataGrid Samples
Multiple samples demonstrating the SfDataGrid control in various scenarios:
- Hospital Management
- Logistic Tracking App
- Banking Transaction
- Financial Tracker
- Employee Directory
- Student Grades Dashboard
- E-Commerce Orders
- Inventory Stock Monitor
- Sales Order Tracker
- Appointment Scheduler
- Product Catalog Viewer App
- Task Management

Location: `SfDataGrid/`
