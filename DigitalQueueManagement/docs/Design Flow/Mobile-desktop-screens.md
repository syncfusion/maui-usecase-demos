
For mobile, keep it extremely clean. Avoid trying to replicate the desktop dashboard. Mobile users should see information in a vertical flow with bottom sheets for details and actions.


Mobile Screen 1 - Queue Overview

Design a modern mobile application screen for a queue management system called "Digital Queue & Counter Manager".

Target device:
Mobile phone
390px width

Design style:
- Clean enterprise mobile UI
- Spacious layout
- Minimal visual clutter
- Modern but realistic
- Blue and teal color palette
- Rounded cards
- Soft shadows
- Large touch targets
- Comfortable vertical scrolling

Top App Bar

Display:
- Queue Overview title
- Current date
- More options icon

Main content:

Section 1:
Queue Summary Cards

Display 4 compact cards in a 2-column grid.

Cards:
- Now Serving
- Waiting Tokens
- Completed Tokens
- Average Wait Time

Each card:
- Large value
- Small label
- Simple icon

Section 2:

Queue Load Card

Contents:
- Radial gauge
- Utilization percentage
- Waiting token count
- Active counters count

Section 3:

Counter Status

Display 3 vertically stacked counter cards.

Each counter card contains:
- Counter name
- Current token number
- Service category
- Queue status badge

Section 4:

Upcoming Tokens

Card title:
Upcoming Tokens

Top right:
Segmented control

Options:
- All
- Normal
- Priority

Display 5 simple token items.

Each item:
- Token number
- Service type
- Priority badge
- Estimated wait time

Bottom Navigation

Items:
- Overview
- Manage

Overview selected.

Important:

- Plenty of space between sections
- No compressed information
- No full-width tables
- Prioritize readability over density
- Modern service-center dashboard experience
